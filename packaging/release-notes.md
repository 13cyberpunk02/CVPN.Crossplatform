Обновления прямо из приложения и исправление «застрявшего» sing-box после сворачивания в трей.

## Новое: обновление из приложения

Больше не нужно скачивать новую версию с GitHub и ставить её вручную. Когда выйдет следующая версия, в «Настройки → Обновления» появится кнопка **«Обновить»**:

1. Приложение скачает файл новой версии, полоса покажет, сколько осталось. Загрузку можно отменить.
2. Файл сверяется с контрольной суммой SHA-256, которую GitHub считает сам. Повреждённый или подменённый файл не ставится и удаляется.
3. Туннель отключается только после удачной загрузки. Если сеть оборвётся на середине, вы не останетесь без VPN.
4. Новая версия ставится и открывается сама.

Как это происходит на каждой платформе:

| Установка | Что происходит |
|---|---|
| Windows, установщик | Установщик в тихом режиме с окном прогресса, Windows один раз спросит права администратора. Выбранные компоненты сохраняются. |
| Windows, портативная | Новые файлы встают поверх папки приложения. |
| Linux, AppImage | Новый файл заменяет старый. |
| Linux, .deb | Пакет ставится через `pkexec`, система спросит пароль. |
| Android | Открывается системный установщик. В первый раз Android попросит разрешить CVPN устанавливать приложения - настройки откроются сами. |

Сам не обновляется только распакованный архив `tar.gz`: для него кнопка ведёт на страницу релиза.

> Эту версию нужно поставить вручную, как обычно: в 1.1.0 и раньше кнопки «Обновить» ещё нет. Следующие версии придут уже через приложение.

## Исправлено

- **sing-box оставался висеть после сворачивания в трей.** Если включено «Подключаться при запуске», открытие окна из трея запускало подключение ещё раз. Второе ядро перехватывало управление, и первое уже нельзя было ни отключить, ни остановить при выходе - только через диспетчер задач. Теперь автоподключение срабатывает один раз за запуск, а подключение поверх работающего туннеля не начинается.
- **При автозапуске с Windows окно не открывалось из трея:** оно пряталось при каждом показе, а не только при старте.
- **Обновление поверх с установленной службой туннеля:** установщик теперь останавливает службу перед копированием файлов и запускает её после. Раньше он мог упереться в занятые файлы.

## Прочее

- К каждому релизу прикладывается `SHA256SUMS.txt` с контрольными суммами всех файлов.

## Файлы

| Файл | Для чего |
|---|---|
| `CVPN-<версия>-setup.exe` | Windows 10/11 x64, установщик |
| `CVPN-<версия>-portable.zip` | Windows x64 без установки |
| `cvpn_<версия>_amd64.deb` | Debian, Ubuntu, Mint и производные |
| `CVPN-<версия>-x86_64.AppImage` | Любой Linux x64: `chmod +x` и запустить |
| `CVPN-<версия>-linux-x64.tar.gz` | Linux x64, архив |
| `CVPN-<версия>-android-arm64.apk` | Android 6+ (arm64) |
| `SHA256SUMS.txt` | Контрольные суммы файлов |

Ставится поверх 1.0.x и 1.1.x, профили, правила и настройки сохраняются. .NET ставить не нужно: он уже внутри.

## Важно знать

- **Linux:** для режима TUN установите службу: «Настройки → Права на TUN → Служба туннеля → Установить». Доступ к ней появится после повторного входа в систему.
- **Linux, трей:** в GNOME нужно расширение AppIndicator.
- **Android:** kill switch включается в настройках Android: «Сеть → VPN → CVPN → Постоянная VPN».
