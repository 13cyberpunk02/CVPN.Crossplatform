Живая статистика с графиком скорости, новые страницы «Соединения», «Логи» и «Маршруты». С ними проще понять, что происходит с трафиком, и настроить правила без знания sing-box.

## Главная страница

- **График скорости за последнюю минуту:** приём и отдача двумя плавными линиями, шкала подстраивается под канал. После отключения график остаётся до следующего подключения.
- **Карточки скорости и правил** получили цветные значки: приём лазурный, отдача фиолетовая. Те же цвета на графике.
- **Итоги сессии** (время, принято, отдано, пик) тоже со значками.

## Соединения

- **Сводка сверху:** всего соединений, сколько через прокси, сколько напрямую и общий трафик. Под ней полоса, которая показывает доли прокси, прямых соединений и ByeDPI.
- **Поиск** по домену, процессу и правилу.
- **В каждой строке:**
  - значок способа выхода: глобус для прокси, стрелка для прямого, молния для ByeDPI;
  - приём, отдача и длительность;
  - полоска, которая сравнивает трафик соединения с самым тяжёлым в списке.
- Кнопки «Напрямую», «Через прокси» и «Блок» с иконками.

## Логи

- **Строки размечены:** время, уровень (`INF`, `WRN`, `ERR`), источник и текст. Ошибки подсвечены красным, предупреждения жёлтым.
- **Поиск** по логу и **фильтр** «Все / Предупреждения / Ошибки» со счётчиками.
- **Пауза:** список замирает, можно спокойно читать. Новые строки копятся и появятся после «Продолжить».
- **Пролистали вверх** - автопрокрутка встаёт сама, вернуться вниз можно кнопкой «К последним».
- **Копирование:** строки выделяются щелчком, несколько - с Ctrl или Shift. Скопировать можно Ctrl+C, Ctrl+A выделяет всё. Есть и меню по правой кнопке мыши.

## Маршруты

- **Подсказка «Как это работает»:** что совпадает, куда отправить и в каком порядке проверяются правила. Закрывается кнопкой «Понятно».
- **Готовые правила в одно нажатие:**
  - блокировать рекламу;
  - российские сайты напрямую;
  - YouTube через прокси;
  - Telegram через прокси.
- **Своё правило по схеме «Что / Куда»:** вместо `domain_suffix` и подобного - понятные названия («Домен и поддомены», «Страна по IP», «Программа»). Под полем ввода объясняется, что именно совпадёт.
- **Список правил:** у каждого правила значок вида, у правила по стране флажок, цветная метка действия. Выключенные правила бледнеют.
- **«Всё остальное»** выбирается двумя кнопками сразу после списка.

## Файлы

| Файл | Для чего |
|---|---|
| `CVPN-<версия>-setup.exe` | Windows 10/11 x64, установщик |
| `CVPN-<версия>-portable.zip` | Windows x64 без установки |
| `cvpn_<версия>_amd64.deb` | Debian, Ubuntu, Mint и производные |
| `CVPN-<версия>-x86_64.AppImage` | Любой Linux x64: `chmod +x` и запустить |
| `CVPN-<версия>-linux-x64.tar.gz` | Linux x64, архив |
| `CVPN-<версия>-android-arm64.apk` | Android 6+ (arm64) |

Ставится поверх 1.0.x, профили, правила и настройки сохраняются. .NET ставить не нужно: он уже внутри.

## Важно знать

- **Linux:** для режима TUN установите службу: «Настройки → Права на TUN → Служба туннеля → Установить». Доступ к ней появится после повторного входа в систему.
- **Linux, трей:** в GNOME нужно расширение AppIndicator.
- **Android:** kill switch включается в настройках Android: «Сеть → VPN → CVPN → Постоянная VPN».
