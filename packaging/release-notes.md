Объёмный интерфейс: новая кнопка подключения и меню, удобная страница профилей, аккуратные карточки соединений.

> Если у вас стоит 1.2.0, эта версия ставится прямо из приложения: «Настройки → Обновления → Обновить».

## Кнопка подключения

- **Объёмная кнопка:** выпуклое стекло с бликом, скосом по краю и тенью.
- **Утопленный желобок** вокруг кнопки, внутри которого бежит светящаяся полоса. Свет неподвижный, поэтому полоса уходит вглубь канала, а не лежит сверху.
- **«Дыхание»:** обводка цвета состояния плавно разгорается и гаснет целиком - лазурная в покое, зелёная при подключении, красная при ошибке. Во время подключения пульс чаще.
- **Наклон за курсором:** при наведении мыши кнопка слегка поворачивается к ней в 3D.

## Меню разделов

- Пункты лежат в утопленном «лотке», у каждого - выпуклая клавиша с иконкой.
- Выбранный раздел приподнят стеклянной плашкой, а его клавиша горит лазурью.
- На телефоне нижнее меню оформлено так же.

## Профили

- **Одно поле для всего:** ссылка на сервер, ссылка подписки `https://` или сразу несколько ссылок, по одной в строке - приложение само поймёт, что это.
- **Быстрые кнопки:** «Вставить из буфера», «Вручную», «Из файла».
- **Подписка** - отдельной карточкой с адресом и датой последнего обновления.
- **Поиск** по имени и адресу, сортировка **«Сначала быстрые»**, «Проверить все» и экспорт одной кнопкой.
- **Карточка сервера:** флаг на объёмной клавише, задержка цветной плашкой с полосками сигнала, отметка «Активен».
- **Сервер выбирается щелчком по карточке** - отдельная кнопка «Выбрать» больше не нужна.
- **Пустой список** встречает понятной подсказкой с первым шагом.

## Соединения

- Приём и отдача - рядом, каждый в своей цветной плашке, а не стрелками вплотную друг к другу.
- Время соединения - отдельной плашкой в углу карточки, кнопки - в одной строке с полоской доли трафика.
- Плитка «Трафик» в сводке - как остальные плитки, значения в строку.
- На телефоне полоска доли больше не наезжает на цифры.

## Исправлено

- **Windows: старая иконка на панели задач.** Прежний WPF-клиент стоял по тому же пути, и Windows показывала его иконку из кэша. Установщик теперь сбрасывает кэш значков.
- **Android: значок в строке состояния** рядом с часами и Wi-Fi теперь белая кнопка питания, а не белый квадрат.

## Файлы

| Файл | Для чего |
|---|---|
| `CVPN-<версия>-setup.exe` | Windows 10/11 x64, установщик |
| `CVPN-<версия>-portable.zip` | Windows x64 без установки |
| `cvpn_<версия>_amd64.deb` | Debian, Ubuntu, Mint и производные |
| `CVPN-<версия>-x86_64.AppImage` | Любой Linux x64: `chmod +x` и запустить |
| `CVPN-<версия>-linux-x64.tar.gz` | Linux x64, архив |
| `CVPN-<версия>-android-arm64.apk` | Android 6+ (arm64) |
| `SHA256SUMS.txt` | Контрольные суммы файлов |

Ставится поверх 1.0.x, 1.1.x и 1.2.0, профили, правила и настройки сохраняются. .NET ставить не нужно: он уже внутри.

## Важно знать

- **Обновление из приложения** работает начиная с 1.2.0. С более старых версий 1.2.1 нужно поставить вручную, как обычно.
- **Linux:** для режима TUN установите службу: «Настройки → Права на TUN → Служба туннеля → Установить». Доступ к ней появится после повторного входа в систему.
- **Linux, трей:** в GNOME нужно расширение AppIndicator.
- **Android:** kill switch включается в настройках Android: «Сеть → VPN → CVPN → Постоянная VPN».
