Исправление для Linux: служба туннеля снова устанавливается из настроек.

> Если у вас стоит 1.2.0 или новее, эта версия ставится прямо из приложения: «Настройки → Обновления → Обновить».

## Исправлено

- **Linux: не устанавливалась служба туннеля.** При нажатии «Настройки → Права на TUN → Служба туннеля → Установить» в журнале появлялось:
  ```
  Не удалось установить службу: /bin/sh: 0: cannot open /opt/cvpn/app/linux/cvpn-service.sh: No such file
  ```
  Скрипт установки службы попадал в пакет в папку `Linux` с большой буквы, а приложение искало его в `linux`. На Windows регистр в именах не важен, поэтому ошибка проявлялась только на Linux - во всех пакетах: .deb, AppImage и tar.gz. Теперь папка называется правильно.
- Если вы обходили ошибку ссылкой `sudo ln -s /opt/cvpn/app/Linux /opt/cvpn/app/linux`, ничего делать не нужно: пакет .deb уберёт её сам при установке.

## Что было в 1.2.2

- **Несколько подписок** с остатком трафика и сроком действия от панели (3x-ui, Marzban, Remnawave и другие), предупреждение, когда подписка на исходе.
- **Сторож подключения:** сервер перестал отвечать - приложение переходит на самый быстрый из остальных; упавшее ядро перезапускается. Выключается в «Настройки → Запуск → Восстанавливать подключение».
- **Android:** плитка в шторке быстрых настроек и сканер QR-кода на странице профилей.
- Повтор при занятом адаптере TUN снова срабатывает, подписки запрашиваются так, чтобы панель отдала список серверов, а не чужой конфиг.

## Файлы

| Файл | Для чего |
|---|---|
| `CVPN-<версия>-setup.exe` | Windows 10/11 x64, установщик |
| `CVPN-<версия>-portable.zip` | Windows x64 без установки |
| `cvpn_<версия>_amd64.deb` | Debian, Ubuntu, Mint и производные |
| `CVPN-<версия>-x86_64.AppImage` | Любой Linux x64: `chmod +x` и запустить |
| `CVPN-<версия>-linux-x64.tar.gz` | Linux x64, архив |
| `CVPN-<версия>-android-arm64.apk` | Android 6+ (arm64) |
| `SHA256SUMS.txt` | Контрольные суммы файлов |

Ставится поверх 1.0.x, 1.1.x и 1.2.x, профили, правила и настройки сохраняются. .NET ставить не нужно: он уже внутри.

## Важно знать

- **Обновление из приложения** работает начиная с 1.2.0. С более старых версий 1.2.3 нужно поставить вручную, как обычно.
- **Linux:** для режима TUN установите службу: «Настройки → Права на TUN → Служба туннеля → Установить». Доступ к ней появится после повторного входа в систему.
- **Linux, трей:** в GNOME нужно расширение AppIndicator.
- **Android:** kill switch включается в настройках Android: «Сеть → VPN → CVPN → Постоянная VPN».
- **Android, плитка:** откройте шторку, нажмите карандаш (изменить) и перетащите CVPN к остальным плиткам.
