Первая кроссплатформенная версия CVPN - клиента sing-box. Теперь на **Windows, Linux и Android**, с новым интерфейсом на Avalonia.

## Что нового

- **Linux и Android** вдобавок к Windows: один интерфейс и одни профили.
- **Новый интерфейс**: свой набор элементов в лазурных тонах, тёмная и светлая темы с переключением, анимации, своя шапка окна.
- **ByeDPI встроен** в версии для Linux и Android: ничего не нужно скачивать и указывать путь. На Windows можно выбрать свой ciadpi, как раньше.
- **Профили и правила** переносятся из прежней версии для Windows как есть.

## Возможности

- VLESS (Reality, WebSocket, XHTTP), AnyTLS, NaiveProxy (кроме Android), подписки и импорт ссылок.
- Маршрутизация по сайтам, geosite/geoip и своим наборам правил: напрямую, через прокси, через ByeDPI или блокировка.
- Режим TUN (весь трафик) или системный прокси.
- Kill switch: на Windows - через брандмауэр, на Linux - nftables, на Android - системная «Постоянная VPN».
- Служба туннеля: TUN без запуска приложения от администратора (служба Windows, юнит systemd на Linux).
- Список соединений, журнал, значок в трее, автозапуск, русский и английский языки.

## Важно знать

- **Linux:** для режима TUN установите службу: «Настройки → Права на TUN → Служба туннеля → Установить». Доступ к ней появится после повторного входа в систему.
- **Linux, трей:** в GNOME нужно расширение AppIndicator.
- **Android:** при первом подключении система спросит разрешение на VPN. Kill switch включается в настройках Android: «Сеть → VPN → CVPN → Постоянная VPN».
- **Android:** только arm64, этого достаточно почти для всех телефонов последних лет.
