Обновлённый интерфейс, вставка профилей из буфера одним нажатием и исправление ложного сообщения о новой версии.

## Исправлено

- **Сообщение «Доступна новая версия» появлялось всегда.** Проверка обновлений смотрела релизы прежнего клиента для Windows. Теперь она смотрит этот проект.
- **Android:** в APK теперь записана версия релиза, а не всегда 1.0.0. Без этого проверка обновлений на телефоне тоже ошибалась бы.

> Версия 1.0.0 ещё спрашивает старый проект, поэтому в ней сообщение останется до установки 1.0.1.

## Новое

- **Вставить из буфера** - главная кнопка на странице «Профили». Скопируйте одну или несколько ссылок на серверы (по одной в строке) и нажмите её. Если в буфере ссылка подписки `https://...`, она подставится и сразу загрузится. Особенно удобно на телефоне.
- **Выбор сервера на главной странице:** переключаться можно, не заходя в «Профили». Если туннель уже поднят, сервер меняется без переподключения.
- **Круг подключения:** вокруг кнопки всегда вращается градиентное кольцо со свечением. В покое оно лазурное, при подключении крутится быстрее, после подключения становится зелёным, при ошибке красным.
- **Лазурный фон главной страницы** в обеих темах, со свечением за кругом подключения.

## Интерфейс

- **Кнопки:** у всех текстовых кнопок теперь есть обводка. Раньше «Проверить все», «Очистить», «Папка логов» и другие выглядели как обычный текст.
- **Профили:** «Поделиться», «Изменить» и «Удалить» стали иконками в строке профиля. У активного профиля вместо кнопки «Выбрать» стоит отметка «Активен».
- **Настройки** разбиты на группы: Подключение, Права на TUN, Запуск, Внешний вид, Обновления, Ядро sing-box.
- **ByeDPI:** включение и запуск вынесены наверх страницы, итоговая команда запуска показана отдельным блоком.
- **Длинные имена серверов** в круге подключения переносятся, а не обрезаются. Задержка показывается только после замера.
- **«Ядро не найдено»** в боковом меню выделено цветом, чтобы проблему было сразу видно.
- **Светлая тема:** плашка состояния в шапке окна снова видна.

## Файлы

| Файл | Для чего |
|---|---|
| `CVPN-<версия>-setup.exe` | Windows 10/11 x64, установщик |
| `CVPN-<версия>-portable.zip` | Windows x64 без установки |
| `cvpn_<версия>_amd64.deb` | Debian, Ubuntu, Mint и производные |
| `CVPN-<версия>-x86_64.AppImage` | Любой Linux x64: `chmod +x` и запустить |
| `CVPN-<версия>-linux-x64.tar.gz` | Linux x64, архив |
| `CVPN-<версия>-android-arm64.apk` | Android 6+ (arm64) |

Ставится поверх 1.0.0, профили и настройки сохраняются. .NET ставить не нужно: он уже внутри.

## Важно знать

- **Linux:** для режима TUN установите службу: «Настройки → Права на TUN → Служба туннеля → Установить». Доступ к ней появится после повторного входа в систему.
- **Linux, трей:** в GNOME нужно расширение AppIndicator.
- **Android:** kill switch включается в настройках Android: «Сеть → VPN → CVPN → Постоянная VPN».
